# Python Website (Flask Full Stack Web App)

## Overview
Built a full-stack web application using Python and Flask, covering authentication, routing, and database integration. The project demonstrates how to create a functional backend-driven website with user accounts and dynamic content.

This project follows a typical web application architecture, including user authentication, database models, and server-side rendering.

---

## How It Works

The application is structured around Flask routes that handle different parts of the website:

- **User Authentication**
  - Users can register, log in, and log out securely
  - Passwords are hashed before being stored in the database

- **Database Integration**
  - Uses a database (typically SQLite with SQLAlchemy)
  - Stores user data and application-related information

- **Routing System**
  - Flask routes handle page navigation (home, login, signup, dashboard, etc.)
  - Dynamically renders HTML templates based on user state

- **Session Management**
  - Maintains user login state across pages using Flask sessions
